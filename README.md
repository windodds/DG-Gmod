该模组使用钩子从底层获取实体受伤事件，并通过 WebSockets 协议将受伤信息发送至接收端。

### 本 mod 对比计算机视觉类插件

**优势：**

- 低延迟
- 绝对精准
- 低资源占用
- 可以随意使用各种 HUD，支持全屏和各种分辨率游玩
- 更强的可扩展性和可自定义支持

**劣势：**

- 多人联机不友好
- 安装较复杂

### 使用方法

1. 订阅并启用该模组。

2. 下载并安装 [GWSockets](https://github.com/FredyH/GWSockets)。

    根据游戏选择 64 位或 32 位，下载最新版。  
    将你下载的 `dll` 文件放在 `garrysmod/lua/bin`，没有 `bin` 文件夹就自己创建。

3. 在 DGHUB 下载、安装并启用 DG-Gmod。

### 为什么不使用 UDP 协议？

- UDP 理论上比 WebSockets 延迟更低，但其实可以忽略。并且启用 Gmod 的 UDP 日志系统可能会造成更高的发送端延迟。虽然可以通过禁用日志缓冲的方法降低延迟，但会增加资源占用。
- UDP 传输可能会丢包、乱序。
- 用户配置不方便。启用 UDP 需要用户每次进游戏在控制台输入指令，当然也可以用 `autoexec`。
- 可读性问题。启用 UDP 日志后，控制台会被日志刷屏。
